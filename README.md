# ישראל ראפ סטאר (IL Rap Star)

סימולטור קריירה של ראפר ישראלי. כל המשחק הוא קובץ אחד: `index.html`. אפשר לפתוח אותו ישירות בדפדפן.

## מבנה

הקובץ `index.html` נבנה אוטומטית מהקבצים בתיקייה `src/`:

| קובץ | מה יש בו |
|---|---|
| `src/1-layout.html` | המסכים והעיצוב |
| `src/2-data.js` | נתונים: אמנים בדויים, חנות, הופעות, הישגים, טינדר, תגובות מעריצים |
| `src/3-events.js` | האירועים האקראיים (מגיעים כהודעות ב־WhatsApp) |
| `src/5-apps.js` | האפליקציות שבתוך המשחק: Spotify, Apple Music, YouTube, Instagram, TikTok, Tinder, WhatsApp |
| `src/6-avatars.js` | דיוקנאות לפרופילים בטינדר (ותמיכה בתמונות מ־`img/tinder/`) |
| `src/4-logic.js` | מנוע המשחק |

## עריכה ובנייה

```
npm install
npm run build
```

הבנייה מחברת את הקבצים ומכניסה את ה־CSS של Tailwind ישירות לתוך `index.html`, כך שהמשחק עובד גם בלי אינטרנט. האייקונים (Font Awesome) עדיין נטענים מהרשת.

כל השמות במשחק (אמנים, שירים, מותגים, תקשורת) בדויים.
