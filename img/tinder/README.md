# תמונות לפרופילים בטינדר

שים כאן תמונות (jpg/png/webp) ורשום אותן ב-`TINDER_PHOTOS` בקובץ `src/6-avatars.js`, למשל:

```js
const TINDER_PHOTOS = ['img/tinder/01.jpg', 'img/tinder/02.jpg'];
```

אחרי `npm run build` הפרופילים ישתמשו בתמונות. בלי תמונות, כל פרופיל מקבל דיוקן מאויר שנוצר אוטומטית.
מומלץ יחס 4:5, ורק תמונות שנוצרו ב-AI (לא של אנשים אמיתיים).
